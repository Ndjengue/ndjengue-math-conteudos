# Conteúdos do NDJENGUE MATH

Currículo público (lições, exemplos e geradores de exercícios) da aplicação NDJENGUE MATH, da 1.ª classe ao Ensino Universitário.

- `curriculo.json` — pacote descarregado pela aplicação em **Definições → Conteúdos → Procurar actualizações**.
- Para publicar uma actualização, aumenta `versao` no ficheiro. A aplicação só instala versões superiores e rejeita o pacote se algum exemplo não for resolvido pelo motor matemático.

Este repositório contém apenas conteúdos educativos. Não contém código da aplicação nem dados de estudantes.
